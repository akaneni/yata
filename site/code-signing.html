Code signing policy

Last updated: October 27, 2026

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: Signing through SignPath Foundation is being set up. Releases are signed starting with the first version published after the project is approved. Until then the installer is unsigned, and each release ships a SHA256SUMS.txt so you can check the file you got.

What is signed

  • Yata.exe, the app itself, signed before it goes into the installer.
  • Yata-Setup-x.y.z.exe, the installer published on GitHub Releases.

Both are built by GitHub Actions on GitHub-hosted runners, from a version tag of the public repository (release.yml). Nothing built on a personal computer is signed, and every signing request is approved by hand. The .NET Desktop Runtime the installer may download comes from Microsoft and carries Microsoft's own signature.

Team roles

  • Committers and reviewers: akaneni. Changes from other contributors are reviewed before they are merged.
  • Approvers: akaneni approves each signing request.

Everyone in these roles uses multi-factor authentication on GitHub and SignPath.

Privacy

Yata has no account, server or telemetry. What it sends over the network, and when, is in the privacy policy; the installer shows a summary before installing.

Checking the signature

Right-click the file, choose Properties, then Digital Signatures. The signer should be SignPath Foundation. Anything else, or no signature on a release marked as signed, is not an official Yata build: please open an issue.
